Firework based on CPU particles.

Features:

- Multi-color firework
- Particle trails with acceleration deviation
- Initial eplosion
- Launching animation
- Sound

Improvements that can be done:

- Blinks of some particles transitioning lightness

- Better initial explosion color transition.
- Horizontal deviation when launching the rocket so
  that it's not always staight vertical direction.
- Reduced probability of whistling sound.
